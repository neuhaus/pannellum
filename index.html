Pannellum WebXR fork

A lightweight panorama viewer for the web, with experimental VR headset support via the WebXR Device API.

Launch the WebXR VR demo

Needs a WebXR-capable browser over HTTPS. Open it on a headset (e.g. Meta Quest) and press the goggles button in the control bar to enter immersive VR.

Bundled examples

  • Standalone viewer — the minified single-file build
  • Simple embed — an <iframe> using the source files
  • Minified embed — the same, using the minified build
  • Cubemap
  • Tour — multiple scenes with hotspots
  • Multi-resolution
